# Prompt: add or change a visual

```
In the Atlas HTML Charts repository (read AGENTS.md), edit <path/to/dashboard.html>.

Add a visual that answers: "<the question, e.g. which products lost margin this quarter?>"

- Pick the visual type from the "Choosing a visual" table in AGENTS.md and explain the choice in one line.
- Copy the closest example from gallery/index.html and adapt its fields to this page's data
  (field names are in the page's data file; check them, don't guess).
- Place it in the grid so the row still adds up to 12 columns; adjust neighbouring spans if needed.
- Only edit the JSON config block. Run `npm run validate`.
```
